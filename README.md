# 🎮 Tic Tac Toe

A simple Tic Tac Toe web game built with **Python and Flask**.

## ✨ Features

* 🎮 Player vs Player
* 🤖 Player vs Computer
* 🟢 Easy, 🟡 Medium, and 🔴 Hard difficulty
* 🧠 Hard mode uses Minimax with alpha-beta pruning
* 💬 Bot dialogue system
* 🎨 Multiple themes
* 🔊 Sound effects and BGM
* 📱 Responsive interface
* 🧪 Python & JavaScript tests

## 🛠️ Tech Stack

* Python
* Flask
* HTML / CSS / JavaScript
* Pytest

## 🚀 How to Run

Clone the repository:

```bash
git clone <your-repository-url>
cd tic-tac-toe
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```

Then open:

```text
http://127.0.0.1:5000
```

## 🧪 Testing

Run the Python tests with:

```bash
python -m pytest -v
```

JavaScript dialogue tests:

```bash
node --test tests/js/bot-dialogue.test.js
```
